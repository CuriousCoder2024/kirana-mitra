# Shelf-scan eval set

Five synthetic shelf photos generated by `make_images.py` with Pillow. Each shows
one to three shelf rows of labelled packs for catalogue brands, with a known
number of units per brand recorded in `labels.json` (the only ground truth).

Why synthetic: a search of Wikimedia Commons (2026-10-18, queries "kirana shop
shelf india grocery", "grocery store shelf India packets") returned no
CC-licensed kirana shelf photo with countable units, and hand-counting real
photos would have made the labels themselves unreliable. Synthetic scenes give
exact counts and let us vary difficulty: `hardness` adds jitter, overlap, blur
and pixel noise.

| Image | Products | Total units | Hardness |
|---|---|---|---|
| shelf_01_easy.jpg | Maggi, Parle-G, Tata Salt | 21 | 0.0 |
| shelf_02_mixed.jpg | 6 brands, two per row | 34 | 0.1 |
| shelf_03_crowded.jpg | 7 brands, up to three per row | 47 | 0.2 |
| shelf_04_sparse.jpg | 4 brands, 1 to 3 units each | 8 | 0.05 |
| shelf_05_noisy.jpg | 6 brands, blur and noise | 34 | 0.35 |

Images are 1024×768 JPEG, each under 1 MB. Source: generated, no licence
restrictions. Regenerate with:

```bash
uv run python -m tests.eval.shelf.make_images
```

Run the eval against a live server:

```bash
uv run python -m tests.eval.shelf.run --base http://localhost:8090
```

Results append to `results.csv` (date, model, recall, precision, exact-count rate,
count MAE, latency).
